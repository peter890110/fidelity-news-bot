# AI 財經新聞分析助手

## 啟動

執行 `npm start` 或 `node server.js`，開啟 http://localhost:4173/ 。Node.js 20 以上，無外部套件或 API 金鑰。Mac 可雙擊 `start.command`。

## 新聞規則：六小時硬性限制

- 僅選擇原始發布時間在最近六小時內的總經、產業或財金新聞，優先兼顧三類。
- 查詢固定 `when:6h`。RSS 初篩後，必須核對原出版者的原始發布時間；不使用修改時間、RSS 收錄時間或本次查詢時間替代。
- 超時、未來、缺少發布時間、時間不明及非財金新聞全部排除。
- 經濟日報與工商時報各三篇，不足就顯示實際篇數或空狀態，不以超時舊文補滿。
- 快取也必須有已核對的原始發布時間，且仍在六小時內。API 載入、更新、限流與失敗路徑都再次檢查，`hours` 參數不能放寬限制。
- 頁面會在新聞滿六小時時自動移除，回到頁面及複製時再次檢查。
- 新聞標題為純文字，每篇三個編號重點，每點200–300字，無每點小標或來源連結。
- 單篇複製與整份報告都輸出純文字。來源網址及核對時間僅存後端供查證。

## 查詢與資料

更新按鈕查詢兩家媒體的 Google 新聞 RSS，讀取公開內文並抽取數據，配合總經觀察規則生成三點。無法核對原始發布時間或內文不足時跳過，不捏造新聞補足篇數。更新查詢有60秒間隔，載入時最多快取五分鐘；六小時資格會即時重新計算。

`report.json` 為已查閱的種子資料；`latest.json` 為執行時快取。Render 免費方案不永久保存快取，重啟時會重新檢查時窗與盤後日期。

## 盤後

台股與美股均採前一個已收盤交易日；新聞六小時規則不改變盤後交易日期。

台股使用證交所實際交易日、全日成交金額與同日三大法人統計；美股四大指數須為同一美東收盤日，排除尚未收盤日線。週末與休市日依實際歷史資料處理。日期無法核對時明確顯示留存資料待核對。

## 部署

既有 Render 免費 Web Service，分支 `codex/macro-news-cloud` 的 `prototype/`。啟動 `node prototype/server.js`，健康檢查 `/healthz`。本機綁定127.0.0.1，Render 使用0.0.0.0及平台 PORT。

`/news-6h`、`/`、`/market-v2`、`/market-v3` 均提供最新版本。公開試作尚未整合企業登入或富達內網。

## 每家三篇與三類選文

經濟日報、工商時報各三篇；在六小時硬性發布時窗內，優先兼顧總經、產業、財金。搜尋已改為兩家媒體全站的六小時新聞，再依內容篩選，擴大產業及資本市場的候選範圍。完整查閱整理仍在時窗內時保留；到期後從新候選替換。未足三篇顯示實際數量，過期快取不會補入。
