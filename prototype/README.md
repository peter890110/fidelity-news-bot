# 財經新聞分析助手

這是一份可以直接閱讀的新聞網頁。初始報告採2026年10月15日至16日的公開報導，經濟日報及工商時報網站各兩篇，每篇三點，每點200–300字。深色版面及四個區塊沿用參考截圖。

## 啟動

在此目錄執行 `npm start`，或使用 Node.js 20 以上執行 `node server.js`，開啟 http://localhost:4173/ 。這台Mac也可雙擊 `start.command`。必須從本機網址開啟，直接開啟HTML檔案無法使用查詢功能。

## 更新的實際行為

- 頁面載入時顯示已完成的完整報告，不需要API金鑰。
- 「獲取最新財經解析」會重新查詢兩家媒體的Google新聞公開RSS，並讀取可取得的原文。
- 當現有精選仍在時間跨度內時，優先保留完整整理；其他新發現的新聞顯示在頁尾展開區。
- 當需要替換較舊精選時，嘗試取得新報導內文，抽取可核對數據，配合總經觀察規則產生三點文字。此類文章標註「數據整理／總經觀察」。它是規則摘要，不是大型語言模型的自由生成；資訊深度會低於本次查閱後撰寫的四篇文章。
- 無法讀取全文、來源暫時失效或沒有足夠數據時，保留上次完整報告。查詢時間與新聞發布時間分開顯示，不會把舊新聞偽裝成新發布。
- 選文條件可篩選主題，複製按鈕會複製完整四篇與市場報告及所有來源。

## 資料與範圍

`report.json` 儲存本次查閱原文後撰寫的報告；`latest.json` 為更新成功後的本機快取。台股與美股盤後為已核對的2026年10月15日收盤快照，附來源與日期；目前不會自動更換盤後快照。

原始報導內文不在網頁公開重刊。文中的「總經解讀／延伸觀察」是分析，與原文事實區別呈現。工商時報第二篇為該網站刊載的時報資訊編譯報導。

本機預設綁定127.0.0.1；在Render環境自動綁定0.0.0.0與平台指定的PORT。雲端部署採免費Web Service，提供公開試作網址，尚未整合富達內網或企業登入。

健康檢查為 `/healthz`。來源查詢最短間隔為60秒。Render免費服務會休眠，重啟時會從初始報告恢復；快取不作永久保存。原始碼放在 `codex/macro-news-cloud` 分支的 `prototype/` 目錄，主程式為 `prototype/server.js`。


## 盤後格式第二版

`/market-v2` 提供更新後版面。美股為四大指數百分比及約200字走勢兩點；台股為成交金額與法人合計、外資／自營商／投信籌碼及約200字走勢三點。畫面與複製報告使用同一個格式函式。

台股收盤資料更新至2026年10月16日，美股為美東10月15日。台股三大法人會在載入與按下更新時向證交所查詢同一天的統計；尚未公布時顯示「待公布」，不混用前一日籌碼。
