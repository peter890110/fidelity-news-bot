# AI 財經新聞分析助手

深色財經新聞報告，分為台股盤後、美股盤後、經濟日報及工商時報。每家媒體兩篇，每篇三個重點，每點200–300字。

## 啟動

執行 `npm start`，或 Node.js 20 以上執行 `node server.js`，開啟 http://localhost:4173/ 。Mac 可雙擊 `start.command`。直接開啟 HTML 檔案無法查詢新聞。

## 報告與複製

- 標題為純文字，不顯示來源連結、作者或每點小標。
- 單篇複製包含標題與三個編號重點。完整報告複製包含目前篩選顯示的新聞與盤後。
- 複製文字不含網址、來源欄位或每點小標。若瀏覽器不允許剪貼簿操作，開啟可選取文字的視窗。
- 原始來源及查閱時間保留在後端資料，供核對使用。

## 盤後日期

- 台股：查詢證交所 FMTQIK 實際成交日期，選擇台北當日之前最近的交易日，再取得同日收盤及三大法人統計。採全日成交金額，含盤後、零股、鉅額。
- 美股：四大指數必須是同一美東交易日，排除台北當天及尚未收盤的美東日線。交易日來自實際歷史報價，可跨過週末與休市日；保留15分鐘等待收盤資料更新。
- 2026/10/19 的台股與美股均顯示 2026/10/16 收盤。美股該日另用中央社收盤報導交叉核對，避免報價小數精度差異。
- 頁面載入與更新按鈕都會核對盤後日期，查詢快取五分鐘，台北日期改變時立即重查。取得新交易日後會重建當日走勢文字，不沿用舊日說明。
- 無法核對日期時，明確顯示「留存資料・待核對」，不把舊日期標成前一交易日。法人未公布時顯示待公布。

## 新聞更新

更新按鈕會查詢兩家媒體的 Google 新聞公開 RSS，再讀取可取得的內文。優先選擇總經、通膨、利率、匯率、GDP 等報導。既有完整整理仍在時間範圍內時先保留；需要替換時以內文數據和總經觀察規則產生三點，無須 API 金鑰。這是規則摘要，初始四篇為查閱原文後撰寫。原文不足、沒有可核對數據或連線失敗時保留完整整理，並顯示較早報導提示。

`report.json` 為已核對的初始報告，`latest.json` 是本機更新快取。Render 免費方案的快取不永久保存，重啟後仍會重新查詢盤後。

## 部署

使用既有 Render 免費 Web Service，原始碼位於 `codex/macro-news-cloud` 分支的 `prototype/`。啟動為 `node prototype/server.js`，健康檢查 `/healthz`。本機綁定127.0.0.1，Render 使用0.0.0.0及平台指定 PORT。

`/`、`/market-v2`、`/market-v3` 均提供最新版本。這是公開試作網址，尚未整合企業登入或富達內網。
